# MNIST-classification-NN-vs-SNN
Un repositorio de ejemplo para la clasificación de imágenes con redes neuronales clásicas y por impulso usando el conjunto de datos MNIST. Incluye implementación en snnTorch y ejemplos prácticos para facilitar la explicación y la experimentación.
En estos experimentos se crearon distintas topologías de red neuronal clásica para obtener un clasificador de imégenes de dígitos escritos a mano en escala de grises. Además de crear las topologías análogas en su versión de impulso con el fin de comparar ambos rendimientos en términos de precisión.
